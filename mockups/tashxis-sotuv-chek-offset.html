TASHXIS — nega bunday (kod dalillari)

1Yangi format generatorida offset UMUMAN YO'Q. «Jami to'landi» bloki faqat L (lom) va bitta N qatori: naqd = jamiS − lomPul — offset bilan to'langan pul ham N (naqt) deb yoziladi. Karta/perech ham shu yerda yutiladi. 15403–15412 (klientSotuvChekYangiGen)
2Preview generatorga offset haqida hech narsa uzatmaydi — opts ichida offset maydoni yo'q. 14980–14985

4Eski (lines2) formatda offset bloki BOR edi, lekin v154.2 dan beri klient tanlangan bo'lsa yangi format return qiladi — eski blok hech qachon ko'rinmaydi (sotuvda klient doim tanlangan). O'sha blokning o'zida ham xato bor: kerak hisobida lom ayirilmaydi (14797), saqlash esa ayiradi (15158) — preview va saqlash farqlanadi. 14796–14804 vs 14956–14988

Saqlash yo'li TO'G'RI ishlaydi (15157–15181): offset faqat kerakligicha ishlatiladi, _kdYopish:true yozuvi to'g'ri tushadi. Muammo faqat CHEK KO'RINISHIda.

TAKLIF TAFSILOTI

  1. klientSotuvChekYangiGen ga yangi opts maydoni: offsetlar: [{zavod, tur, gramm, kurs, summa}] (ishlatilgan ulush — saqlashdagi _svRowUsed formulasi bilan bir xil).
  2. «Jami to'landi» blokida L dan keyin O qatorlari, keyin N = jamiS − lomPul − offsetJami. Karta/perech kiritilgan bo'lsa N o'rniga K/P qatorlari (hozirgi N-yagona mantig'i ham aslida karta/perechni yutadi — bu ham tuzatiladimi, qaror №3).
  3. Ostatka jadvaliga offset manbai turi «(bizda)» belgisi bilan kiradi: eski −5.00 → yangi +5.00 → jami 0.00.
  4. Preview chaqiruvida offsetlar hisoblanib uzatiladi (kso-blok ochiq qatorlar, ishlatilgan ulush bilan).
  5. Print/saqlangan chek ham SHU generatordan chiqadi — tuzatish ikkalasiga birdek ta'sir qiladi.

TAXMIN BLOKI

1. ANIQ BILMAYOTGAN JOYLARIM
  • O qatori matni qanday bo'lsin: «3D aylantirildi 5.00g x 60» (to'lov chekidagidek) yoki boshqa matn?

  • N-yagona muammosi (karta/perech ham N deb chiqishi) shu versiyada tuzatilsinmi yoki alohida? Bu offset masalasidan kengroq.
2. TAXMINLARIM
  • Ishlatilgan ulush formulasi saqlashdagi bilan AYNAN bir xil bo'ladi (_needBeforeOffsetSv — lom va skidka ayirilgan). (mendan — preview saqlash bilan mos bo'lishi shart)

  • Umumiy Summa qatori o'zgarmaydi — offset to'lov turi, summaga ta'sir qilmaydi. (mendan)
