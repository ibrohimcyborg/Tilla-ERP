NIMA BUZILGAN — uch alohida buzilish

1. Yuklanishda kassa filtri zaharlanadi. Skript tartibi: 3927 → 10345. Ikkinchisi keyin ishlaydi, demak ilova ochilganda _khFiltr='all'. Kassa filtri (4463): 
_khFiltr==='hammasi' || r.manba===_khFiltr   // 'all' hech qaysiga mos emas
→ kassa lentasi BO'SH ochiladi. Dropdown (4479) esa 'all' ni topolmay birinchi variant «hammasi» yorlig'ini ko'rsatadi — ko'rinishda hammasi joyida, aslida ro'yxat bo'sh. Ayni siz aytgan «kh-filtr paneli buzilgan».
2. Kassa dropdown'i noto'g'ri funksiyani chaqiradi. 3930 dagi function khFiltrTanla hoisting bilan o'rnatiladi, keyin 10358 dagi window.khFiltrTanla= uni bosib ketadi. Endi kassa dropdown'ida variant tanlansa:
  • renderKassa() chaqirilmaydi — kassa yangilanmaydi (filtr «o'lik» ko'rinadi)
  • buning o'rniga renderKlientHisobot() chaqiriladi va klient hisobot filtriga 'avto'/'snab' kabi yot qiymat yoziladi → 10413 hech nimaga mos kelmaydi → klient hisoboti ham bo'shab qoladi, 10506 dagi «amal yo'q» xabari ham chiqmaydi (_cnt['avto']===0 → undefined===0 → false).
3. _khOchiq tip to'qnashuvi (boolean vs obyekt). Kassa khToggle bosilsa _khOchiq=true (boolean) bo'ladi. Keyin klient hisobotida kun bosilsa (10354–10355): _khOchiq[sana]=... — boolean'ga xossa yozish jimgina yo'qoladi → kunlar ochilmay qoladi. Teskarisi ham: hisobot chizilgach _khOchiq obyekt → kassada if(!_khOchiq) doim false → kassa paneli yopilmay qoladi.
