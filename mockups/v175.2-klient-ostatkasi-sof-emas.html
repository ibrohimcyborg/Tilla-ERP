«Klient ostatkasi» sof qoldiq bo'lmasin

v175 dagi xatoni tuzatish · 2026-08-16 · kod yozilmagan
Siz haqsiz, bu mening xatoyim. v175 da klient PDF iga sof qoldiq (klient qarzi minus bizning qarz) yuborgandim. Siz aytgan qoida boshqa: ikkalasi alohida ko'rsatilishi kerak.

1 · Sizning qoidangiz

Siz aytdingiz:

«klient umumiy 100g qarz · bizning qarzimiz 5g · Jami 95g EMAS · jami 100g klient ostatkasi · bizning qarz 5g qilib ko'rsatgani yaxshi»

Bizning qarzimiz yo'qolib ketadi — u alohida ko'rinmaydi.

Ikkala raqam ko'rinadi, hech nima yashirilmaydi.

Mavjud funksiya allaqachon bor va aynan sizning qoidangiz bo'yicha ishlaydi — _qarzJamiRows (16659):

// musbat qatorlar -> klient qarzi, manfiylar -> bizning qarz. Qo'shilmaydi.
(qarz_tarkib||[]).forEach(function(b){
  if(b.qarz>0) ost += b.qarz;   // KLIENT OSTATKASI
  else           biz += -b.qarz;  // BIZNING QARZ
});
return {ostatka: ost, bizQarz: biz};

Men v175 da buni ishlatmasdan, o'zim yig'indi hisoblagandim:

var jami_qolgan = qarz_tarkib.reduce(function(a,b){ return a+b.qarz; }, 0);
                                              ↑ musbat va manfiy QO'SHILADI = sof qoldiq

Qarz chekida «BIZNING QARZ» 0 bo'lsa umuman chizilmaydi. Klient PDF da ham shunday bo'lsinmi, yoki 0.00g deb tursinmi? (katak jadval bo'lgani uchun ustunni yashirish qiyinroq — men 0.00g qolsin deb o'ylayman)
Eslatma: v175.1 (zavod ostidagi «Jami:» qatorini olib tashlash) yozildi va sinovdan o'tdi, lekin hali commit qilinmadi — siz «oldin mockupda ko'rsat» dedingiz. Aytsangiz ikkalasini birga chiqaraman.
